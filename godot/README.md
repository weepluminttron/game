# Aim Trainer · Godot 客户端版

网页版的桌面客户端移植，使用 **Godot 4.3+（GDScript）** 编写，无需联网、无需浏览器，双击即可运行。

## 运行方式

1. 安装 [Godot 4.3 或更新版本](https://godotengine.org/download)（标准版即可，不需要 .NET 版）
2. 在 Godot 项目管理器中点击「导入」，选择本文件夹中的 `project.godot`
3. 点击运行（F5）

## 功能（与网页版对齐）

- 三种模式：六目标 / 跟踪 / 极速切换
- 可调时长、靶子大小、移动速度、靶子生成方向（单面/多面）
- 灵敏度支持滑块和直接输入（无畏契约 0.07°/计数 换算）
- 视角控制：锁定鼠标（默认）或按住右键拖拽
- 视角平滑三档：跟手 / 平衡 / 稳定
- 实时统计得分、击杀、命中率、射击次数，最佳成绩保存在本地
- 管理员模式：菜单底部「管理员」，输入密码解锁辅助功能（自动开枪 / 瞄准辅助，范围与强度可调）
- 多用户系统：每个用户一个独立数据库（`user://users/用户名.cfg`），独立保存设置、最佳成绩和最近 20 局历史
- 用户登录密码：创建用户时设置密码，登录时校验（旧用户未设密码的可留空登录）；开启自动登录后本机免密进入
- 自动登录：登录界面勾选「自动登录」，下次启动直接进入上次的用户
- 排行榜：菜单「排行榜」查看本机所有用户在三种模式下的最高分前十

## 导出 Windows 客户端

1. 项目 → 导出 → 添加 Windows Desktop 预设
2. 选择导出目录，点击「导出项目」即可生成 exe

## 说明

- 项目使用 GDScript（Godot 原生语言），不依赖 .NET SDK
- 界面中文通过系统字体显示（Windows 自带微软雅黑；其他系统可安装 Noto Sans CJK）
- 辅助功能只作用于本训练器，不涉及任何外部程序
