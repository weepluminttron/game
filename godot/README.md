# Aim Trainer · Godot 客户端

使用 **Godot 4.3+（GDScript）** 编写，账号、成绩、排行榜全部由云端服务器管理。

## 运行方式

1. 安装 [Godot 4.3 或更新版本](https://godotengine.org/download)（标准版即可）
2. 项目管理器 → 导入 → 选择 `project.godot`
3. 按 F5 运行

## 功能

- 四种模式：六目标 / 四目标 / 跟踪 / 极速切换
- 可调时长、靶子大小、移动速度、靶子生成方向（前/后/左/右/环绕）
- 灵敏度支持滑块和直接输入（无畏契约 0.07°/计数 换算，三位小数精度）
- 灵敏度校准：180° 自然甩动自动推荐灵敏度并一键应用
- 多游戏灵敏度换算：瓦洛兰特 / CS2 / Apex / 守望先锋2 / 彩虹六号 / 使命召唤
- 可调视野 FOV（70°~110°）、准星大小三档、准星颜色五色
- 视角控制：锁定鼠标（默认）或按住右键拖拽；视角平滑三档
- 分辨率（720P~2K/1024×768）与全屏、真实拉伸开关
- 实时统计：得分、击杀、命中率、射击、未命中；结算页含击杀/秒、平均反应、平均瞄准偏差、大幅拉枪次数
- Esc 暂停菜单：继续 / 退出
- 云端登录：登录界面填服务器地址（默认 `http://123.207.58.61:3000`）、用户名、密码，点「登录 / 注册」自动注册
- 成绩自动上传服务器，排行榜显示全服前十；自动登录可记住账号密码
- 启动时自动检查服务器新版本，发现更新可一键打开下载链接
- 管理员模式：菜单底部「管理员」，输入密码解锁辅助功能（自动开枪 / 瞄准辅助）

## 导出 Windows 客户端

1. 项目 → 导出 → 添加 Windows Desktop 预设
2. 导出项目生成 exe（与 pck 一起分发）

## 说明

- 使用 GDScript，不依赖 .NET SDK
- 界面中文通过系统字体显示（Windows 自带微软雅黑）
- 辅助功能只作用于本训练器，不涉及任何外部程序
